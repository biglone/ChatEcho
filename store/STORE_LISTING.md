# Chrome 网上应用店上架资料

## 基本信息

- **名称：** ChatEcho: ChatGPT 自动朗读
- **语言：** 中文（简体）
- **类别：** 生产力
- **分发方式：** 非公开（Unlisted），可通过链接安装
- **官网 / 支持：** https://github.com/biglone/ChatEcho
- **隐私政策：** https://github.com/biglone/ChatEcho/blob/main/PRIVACY.md
- **用途：** 自动朗读 ChatGPT 助手回复

## 简短说明

用浏览器本地语音朗读 ChatGPT 新回复。可设置语音和语速，并控制暂停、继续、停止与重播。

## 详细说明

ChatEcho 在 ChatGPT 回复生成完成后，使用 Chrome 的本地语音引擎朗读回复。无需 API Key，不调用 OpenAI API。

**主要功能**

- 自动朗读 ChatGPT 新回复，可随时开启或关闭。
- 选择系统提供的语音并调整语速。
- 暂停、继续、停止或重播最新回复。
- 跳过代码块，清理 Markdown 标记，并对长文本分段朗读。
- 设置保存在本机浏览器中。

**隐私说明**

启用自动朗读后，扩展会在本机读取 ChatGPT 助手回复文本并传给 Chrome 的本地语音引擎。扩展排除远程语音，回复内容不会上传到开发者或第三方服务器。扩展不包含分析、广告或跟踪代码。完整说明请查看隐私政策。

**注意：**声音和自动播放能力受浏览器、操作系统和系统语音支持情况影响。ChatGPT 页面更新可能影响回复识别。

## 商店隐私表单填写参考

- 数据类型：网站内容（ChatGPT 助手回复文本），在本机处理以提供语音朗读功能。
- 数据是否出售或转移：否；扩展不向开发者或第三方服务器传输内容。
- 数据存储：只有扩展设置保存在浏览器本地 `storage.local`。
- 用户可见授权：自动朗读默认关闭。弹窗在开关旁说明开启后读取回复，并显示“回复内容仅在本机处理，不会上传”。用户主动开启后才自动处理回复。
- `storage` 权限：保存本地偏好设置。
- `tts` 权限：调用 Chrome 本地文本转语音能力；不使用远程语音。
- ChatGPT 主机权限：仅用于在 ChatGPT 页面读取回复并提供朗读。
- 不申请 `activeTab`、`tabs` 等额外页面权限；仅使用 `storage` 和 `tts` 权限及必要的 ChatGPT 主机权限。

## 提交步骤

1. 登录 [Chrome 网上应用店开发者控制台](https://chrome.google.com/webstore/devconsole/) 并完成开发者账号注册。
2. 创建新项目，上传 `dist/ChatEcho-0.1.8-chrome.zip`（后续版本以 manifest 中的版本号命名）。
3. 按上面的基本信息填写商店说明，上传 440×280 宣传图和至少一张 1280×800 截图。
4. 在隐私实践页按上面的数据处理说明填写网站内容、本地处理、设置存储及权限用途，并填写公开隐私政策链接。
5. 选择非公开（Unlisted）分发，提交审核。审核通过后可复制安装链接。
